АТЛАС АНАТОМИИ — ЛОКАЛЬНАЯ ПРОВЕРКА И ПУБЛИКАЦИЯ

В комплекте:
- index.html — главное меню Atlas (разделы «Скелет» и «Мышцы»);
- muscles.html — интерактивный раздел мышц;
- muscle_data.js — 3D-данные 284 мышечных моделей;
- остальные PNG и manifest — значки и метаданные приложения.

ПРОВЕРКА НА ТЕЛЕФОНЕ БЕЗ GITHUB
1. Скачайте ZIP и откройте его в приложении «Мои файлы».
2. Нажмите «Извлечь» и распакуйте архив в отдельную папку.
3. Откройте распакованную папку Atlas.
4. Нажмите index.html и выберите Chrome или другой браузер.
5. В главном меню откройте единственный пункт «Мышцы».

Важно: GitHub для локальной проверки не нужен. Сам HTML-файл отображается в браузере телефона. Для 3D-графики браузеру нужен интернет, чтобы загрузить Three.js с CDN. Если файловый менеджер открывает HTML через content:// и связанные файлы не загружаются, откройте папку через локальный HTTP-сервер или разместите её на GitHub Pages.

ПУБЛИКАЦИЯ НА GITHUB PAGES
Загрузите ВСЕ файлы и папки из этого комплекта в корень репозитория. Не загружайте только index.html: muscles.html и muscle_data.js обязательны. Затем включите GitHub Pages для ветки и корня репозитория.

УПРАВЛЕНИЕ
- палец / мышь — вращение модели;
- жест двумя пальцами / колесо мыши — масштаб;
- список или нажатие на модель — выбор мышцы;
- «Изолировать» — показать выбранную мышцу отдельно.
